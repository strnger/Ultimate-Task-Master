### What It Does
A RuneLite plugin for OSRS that helps players track and manage in-game league tasks (Raging Echoes).

Key features:
- Near Me spatial query: Find tasks near player position via crowdsourced location data
- Task completion detection: Chat message regex (Dink pattern), future: bitpacked varp reading
- Crowdsourced locations: Players complete tasks, plugin records position, builds heatmap
- Side panel UI: Two tabs (All Tasks / Near Me) with search, sort, filter
- World/minimap overlays: Highlights nearby task locations in-game
- World map markers: Task locations on the world map
